install: the skills, where each agent reads them

The skills are thin scripts over this binary, embedded in it so they always
match it. This writes them where Cursor, Claude Code, or GitHub Copilot reads
skills, stamped with the version, and keeps them out of git. After an
upgrade, --check names the skills that no longer match.

With --profiles it vendors instead the release's profiles, and the
agent-core declarations they read, into .scrum-master, with a manifest of
the release and each file's digest; a rerun keeps what a person edited and
reports what drifted (GH-29). The release comes from install.sh's
SCRUM_MASTER_HOME, the agent installed beside it. With --profiles --check it
holds the vendored files to the manifest instead, writing nothing, and
fails on one edited or missing (GH-35).

Command:
  tpm install   write the embedded skills for an agent, or with --profiles vendor the profiles they run (srd037)

See: srd037
