admission: when an issue is ready to work

An issue is ready when it is open, unassigned, and admitted. Admission is a
script, so it means the same thing in every repository: exactly one plane, a
component listed by a subsystem SRD, one kind on data issues, Requirements and
Acceptance Criteria where the policy asks for them, every criterion naming
its test and environment, and every Cites line pinned. A failing issue gets
needs-triage with each reason in a comment; fixing it and linting again
clears it.

Commands: tpm issue file, tpm issue lint

See: srd013, srd001, srd041
