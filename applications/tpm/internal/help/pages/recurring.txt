recurring: a recurring issue, a subscription to an artifact or an audit

A recurring issue is the same job run every period: a weekly status, an
audit, a release push. Each run closes the instance with a run summary and
opens the next, its Previous Runs section growing by one line. Audits are
recurring issues the ordinary loop works on a schedule.

Commands: tpm issue recur, tpm reports status-issues

See: srd013, srd001
