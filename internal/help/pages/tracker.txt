tracker: where the program's facts live, and keeping a clone current

The tracker is a git repository of its own holding the program's issues,
labels, milestones, and comments, served by beads (srd042). Its
.beads/config.yaml sets the program's issue ID prefix, so an issue's ID
names its program; tpm init sets it once. Every command
reads and writes it through a local clone and names the tracker commit it
read. A clone that is offline queues its writes and makes its pops
provisional; reconcile pushes them once the tracker is reachable.

Subcommands:
  tpm tracker export      write every issue as bd's JSONL, for bd import (srd042)
  tpm tracker migrate     move a tracker to one file per issue, once (srd042)
  tpm tracker reconcile   push queued writes, confirm or lose provisional pops (srd042)

See: srd042
